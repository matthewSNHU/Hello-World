Artemis Financial Vulnerability Assessment Report

This project demonstrates my ability to identify software vulnerabilities, implement security improvements, and verify that an application remains functional after security updates.

Reflection:
Who was Artemis Financial, and what problem were you solving?
Artemis Financial is a financial services company that needed to improve the security of its web application. My role was to identify vulnerabilities, strengthen the application's security, and help protect sensitive customer data.

What did you do well?
I did a good job analyzing vulnerability reports, identifying risks, and implementing security improvements. Secure coding is important because it helps prevent cyberattacks, protects customer information, and builds trust in an organization.

What was challenging or helpful?
The most challenging part was understanding which vulnerabilities required immediate attention and which were false positives. Learning how to interpret security reports was also one of the most valuable skills I gained.

How did you increase security?
I added HTTPS encryption, reviewed dependencies for vulnerabilities, and followed secure coding practices. In the future, I would continue using tools such as Dependency-Check, static analysis tools, and OWASP resources to identify and mitigate security risks.

How did you ensure the application was secure and functional?
After making security improvements, I tested the application and reran vulnerability scans to verify that it still worked correctly and that no new security issues had been introduced.

What resources or tools were most helpful?
Some of the most useful tools were Maven Dependency-Check, Java Keytool, Spring Security, debugging techniques, and vulnerability assessment reports. These tools helped me understand how security fits into the software development process.

What would you show future employers?
I would share my Artemis Financial Vulnerability Assessment Report because it demonstrates my ability to analyze security risks, implement solutions, and validate secure software practices. It reflects both my technical skills and my understanding of software security principles.
